# ローカルモデル運用ルール（Codex CLI + Ollama）

このワークスペースは Colab T4 上のローカル LLM（Ollama 経由）を Codex CLI
から使っています。量子化された小型モデルには以下の癖があるため、必ず
守ってください（手順書 §5.8・§5.8.1 で実機確認済み）。

> このルールセットは **qwen2.5-coder 系専用**の回避策です。
> apply_patch で訓練されたモデル（Devstral など）には逆効果になるため、
> `AGENTS_RULESET=minimal` を使ってください。

## ファイルの作成・編集は apply_patch を使わない

`apply_patch` が要求する unified diff 形式（`@@` ヘッダ等）をこのモデルは
安定して組み立てられません。「Let's apply this patch using the apply_patch
tool.」のように宣言だけして実際には何も書き込まない不具合が実機で確認
されています。

**ファイルを書く／書き換えるときは、必ず shell ツール（exec_command）で
heredoc を使い、ファイル全体を書き直してください:**

```
cat > path/to/file.py << 'EOF_FILE'
（ファイルの内容全体）
EOF_FILE
```

## 先に宣言してから動くな。まずツールを呼べ

「〜します」「〜しましょう」という説明だけを書いて、実際のツール呼び出しを
しないまま応答が終わることがあります。**説明を書く前に、まずツールを
呼び出してください。** 説明が必要なら、実行結果を報告する形で後から
書いてください。

コマンドを提示して「実行してください」とユーザーに頼むのも禁止です。
提示したコマンドは、あなた自身が exec_command で実行してください。
ユーザーは手で実行しません。

## 書いたら自分で確認する

ファイルを書き込んだ直後に `ls -la` と `cat` で **中身が空でないこと** を
自分で確認してから、完了を報告してください。空ファイルのまま「実装しました」
と言い切らないでください。

## 1 ファイルずつ、小さく

複数ファイルを同時に頼まれても、1 ファイルずつ順番に書き込んでください。
複数ファイルを一度に処理させると上記の不具合が起きやすくなります。

## 報告は日本語または英語で

他の言語に切り替えないでください。
