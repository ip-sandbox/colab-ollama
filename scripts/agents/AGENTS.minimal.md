# ローカルモデル運用ルール（Codex CLI + Ollama）

このワークスペースは Colab T4 上のローカル LLM（Ollama 経由）を Codex CLI から
使っています。クラウドの大きいモデルより生成が遅く、1 応答が長いとそれだけで
時間を食います。以下を守ってください。

## 先に宣言して止まるな。まずツールを呼べ

「〜します」「〜しましょう」と書いただけで、実際のツール呼び出しをしないまま
応答を終えないでください。**説明より先にツールを呼び、実行結果を報告する形で
あとから書いてください。**

コマンドを提示して「実行してください」とユーザーに頼むのも同じく禁止です。
提示したコマンドは、あなた自身が shell ツールで実行してください。
ユーザーは手で実行しません。

## 書いたら自分で確認する

ファイルを書き込んだ直後に `ls -la` と `cat` で **中身が空でないこと** を
自分で確認してから、完了を報告してください。
空ファイルのまま「実装しました」と言い切らないでください。

## 1 ファイルずつ、小さく

複数ファイルを同時に頼まれても、1 ファイルずつ順番に処理してください。
1 回の応答はできるだけ短くしてください。

## 報告は日本語または英語で

他の言語に切り替えないでください。
